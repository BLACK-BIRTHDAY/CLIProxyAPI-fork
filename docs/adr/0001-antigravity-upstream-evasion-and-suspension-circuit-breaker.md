# Antigravity Upstream Evasion and Suspension Circuit Breaker

Status: accepted

Google Cloud Code (`daily-cloudcode-pa.googleapis.com` / `cloudcode-pa.googleapis.com`) enforces multi-layer anti-abuse heuristics against third-party clients using Antigravity OAuth credentials, including User-Agent + Piper changelist (`cl`) validation, HTTP/1.1 no-ALPN transport fingerprinting, system instruction inspection for coding-agent harnesses (such as `built on Anthropic's Claude Agent SDK`, `Claude Code`, `Eta`, `Cherry Studio`, and `RFC 2119`), and account-level `403 PERMISSION_DENIED` (`TOS_VIOLATION` / `VALIDATION_REQUIRED`) suspensions.

We decided to:
1. Enforce a unified **Client Wire Fingerprint** (`HTTP/1.1` with empty TLS `NextProtos` and verified `antigravity/hub/<version> (aidev_client; os_type=windows; arch=amd64; cl=<cl>)` User-Agent plus private installation salt) across all Antigravity outbound paths—including inference, token refresh, `loadCodeAssist`, `onboardUser`, and `fetchAvailableModels`—with optional environment overrides (`ANTIGRAVITY_INSTALLATION_SALT`, `ANTIGRAVITY_DISABLE_BACKGROUND_PROBES`, `ANTIGRAVITY_PROBE_INTERVAL`) so co-located Windows and Cloud Run instances sharing credentials neither diverge in fingerprint nor double-poll upstream endpoints.
2. Apply hybrid **System Instruction Cloaking** strictly to `request.systemInstruction`: rewrite the exact high-risk subagent identity sentence (`You are a Claude agent, built on Anthropic's Claude Agent SDK.`) to the canonical Antigravity identity declaration while applying zero-width space (`​`) obfuscation to a built-in default list of third-party agent/client fingerprints (merged with user-configured `sensitive-words`), preserving persona fidelity for downstream clients such as Cherry Studio and Android Eta without mutating user messages or tool schemas.
3. Implement a **Service-Scoped Suspension** circuit breaker and **Failover Contagion** backoff: classify `403` responses carrying `TOS_VIOLATION` or `VALIDATION_REQUIRED` as 24-hour credential-scoped cooldowns, skip suspended/cooling credentials during background `fetchAvailableModels` and `loadCodeAssist` probes, and inject randomized backoff jitter (`800ms–2000ms`) before failing over across credentials on a `403` rejection.
